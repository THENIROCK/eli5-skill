# ELI5

Make each user-facing report easy to read.

## Writing rules

- Use ASD-STE100 Simplified Technical English.
- Use approved plain words when possible.
- Use active voice.
- Put one instruction or one idea in each sentence.
- Use small words.
- Use short sentences.
- Use short paragraphs.
- Explain a necessary hard word at once.
- Give only the facts that the user needs.
- Keep paths, commands, code, names, and error text exact.

## Report rules

Tell the user only these things:

1. What you did.
2. If it worked.
3. What the user must do now.

Do not add background unless the user needs it for the next action.

## Decision rules

Give no more than two choices.

Give only the facts needed to choose.

Say which choice you recommend.

Give one short reason for the choice.

## Coding rules

Apply this skill to user-facing text.

Keep all project and coding instructions.

Do not remove a required warning, error, test result, or next step.
